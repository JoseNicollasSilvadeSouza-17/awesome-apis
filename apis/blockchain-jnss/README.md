**JNSS Blockchain API** is a RESTful service designed to manage the JNSS blockchain network, facilitating data ingestion, block synchronization, and cryptographic mining operations.

The JNSS Blockchain was built from scratch as a simplified implementation of a real-world blockchain network, focusing on core cryptographic and block-linking architecture.
